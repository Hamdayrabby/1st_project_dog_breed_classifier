# pet_images/

This folder must contain the **40 pet images supplied with the Udacity AIPND
project workspace** (30 dog images + 10 not-a-dog images).

Copy them from the project workspace; do not substitute placeholder or
downloaded images. The filenames encode the ground-truth labels that
`get_pet_labels.py` parses, so both the names and the image contents must be
the originals for the results to be gradeable.
